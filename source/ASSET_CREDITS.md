# Icon and illustration sources

Navigation and controls: Lucide Icons, downloaded from the official lucide-icons/lucide repository. See icons/LUCIDE-LICENSE.

Color illustrations: Microsoft Fluent Emoji, official microsoft/fluentui-emoji repository. See art/FLUENT-EMOJI-LICENSE.

- flashcard: https://raw.githubusercontent.com/microsoft/fluentui-emoji/main/assets/Card%20index/3D/card_index_3d.png
- quiz: https://raw.githubusercontent.com/microsoft/fluentui-emoji/main/assets/Memo/3D/memo_3d.png
- calculation: https://raw.githubusercontent.com/microsoft/fluentui-emoji/main/assets/Abacus/3D/abacus_3d.png
- hero: https://raw.githubusercontent.com/microsoft/fluentui-emoji/main/assets/Open%20book/3D/open_book_3d.png

- cheatsheet: https://raw.githubusercontent.com/microsoft/fluentui-emoji/main/assets/Spiral%20notepad/3D/spiral_notepad_3d.png

- Rename folder: Lucide Pencil SVG, https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/pencil.svg

- Flashcard controls: official Lucide star.svg and lightbulb.svg, https://github.com/lucide-icons/lucide/tree/main/icons

- Quiz audio control: official Lucide volume-2.svg and volume-x.svg, https://lucide.dev/icons/volume-2 and https://lucide.dev/icons/volume-x.
- Correct/incorrect feedback sounds: original synthesized sine tones using browser Web Audio; no external recordings.

- Account/group controls: official Lucide users.svg, share-2.svg, copy.svg, log-out.svg, mail.svg, user-round.svg; https://github.com/lucide-icons/lucide/tree/main/icons
- Google sign-in mark: Google-hosted G icon, https://www.gstatic.com/images/branding/product/1x/gsa_48dp.png

- Mathematical rendering: KaTeX 0.19.0 from the official npm katex package; https://katex.org/docs/api. Bundled script, stylesheet, fonts and license are under vendor/katex/.
