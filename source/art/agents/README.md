# Pixel tutor assets

`tutor-atlas.png` is an original transparent 2 by 2 avatar atlas, created with the built-in imagegen tool. It is displayed with CSS quadrant positions and animated with CSS teaching/idle poses. No external account or API key is needed to display the avatars.

Layout: explorer (top left), cloud dog (top right), fox scholar (bottom left), pig inventor (bottom right).

Prompt summary: Create one transparent 2 by 2 pixel-art tutor atlas: an original orange-jacket explorer with a blue book, an ivory cloud dog with mint bandana, a golden fox scholar with navy cloak, and a pink pig inventor with teal overalls. Keep each full-body character centered in an equal quadrant, with consistent scale, dark outlines, crisp pixels, transparent padding, no text or logos. Original designs inspired by the reference style.

The generated source was copied from the imagegen output into this project. Existing anime characters were used only as a broad pixel-art reference; these are original tutor designs.

## Generation prompt

Create one production UI game sprite atlas asset: a precisely aligned 2 by 2 grid of FOUR distinct original friendly pixel-art study tutor characters, on a genuinely transparent background. Square canvas, equal square quadrants. Each full-body character centered in its own quadrant with generous transparent padding, no overlap. Top-left: original spiky dark-haired young orange-jacket adventurer with a tiny blue book, no existing anime character costume or logos. Top-right: fluffy ivory cloud dog with a mint bandana and book satchel. Bottom-left: cheerful golden fox scholar with navy cloak, small round glasses and a book. Bottom-right: round pink pig inventor with teal overalls and tiny round glasses. Match the charm, chunky visible pixels, dark outlines, and retro RPG sprite aesthetic of the user's pixel character reference; original designs. All four stand facing forward in relaxed teaching pose, small readable faces, consistent scale and feet alignment. Crisp hard pixel edges, compact limited palette, absolutely no blur, no soft shadows, no text, no labels, no backgrounds, no watermark. A single transparent game sprite atlas to be displayed at small sizes, not a mockup or screenshot.

Motion is implemented separately: avatars walk between bounded floor positions, reserve available desks, pause to read/write, and move to the front during real teaching jobs. The teacher-selection controls stay stationary. Reduced-motion users see static avatars.
