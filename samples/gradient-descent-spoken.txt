This short lecture explains gradient descent. We want to minimize a differentiable loss function. The gradient points toward local increase, so we subtract the learning rate times the gradient from the current parameter. The learning rate controls the step size. A small learning rate can make progress slow, while a large learning rate may overshoot or diverge. For the loss w squared, the gradient is two times w. If w is three and the learning rate is zero point one, the gradient is six. The updated value is three minus zero point one times six, which equals two point four. Full batch gradient descent uses all training examples. Stochastic gradient descent uses one sampled example. A zero gradient indicates a stationary point, but does not prove a global minimum.
